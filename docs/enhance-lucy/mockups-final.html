Decision Tree Reference

Two loops, two score types. Inner loop uses Dry Run (Eval) Scores. Outer loop uses Training (Finetune) Scores.

INNER LOOP — Dataset Iteration (Dry Run Scores)
Step A: Check dry run mean score
  < 0.25 → Too hard (loosen grader / simplify prompts)
  0.25-0.65 → Healthy → continue
  > 0.65 → Too easy (tighten grader / add harder records)

Step B: Check dry run std deviation
  < 0.10 → No differentiation (add partial credit)
  0.10-0.25 → Healthy → continue
  > 0.25 → Bimodal (add intermediate scoring)

Step C: Per-topic dry run analysis
  Low score + few records → Add records + simplify
  Low score + enough records → Read grader reasons → fix
  Mid score → Check cross-iteration trend

Step D: Grader health check (from dry run)
  Reasons make sense? → Trust scores
  Inconsistent? → Add contrastive examples
  High scores but low quality? → Reward hacking risk

Step E: Cross-iteration comparison (dry run)
  Improved > 0.03? → Changes worked, iterate or train
  Plateau? → ESCALATE to different lever

Step F: Cross-model comparison (dry run)
  Strong model passes, target fails? → Prompts need work
  Both fail? → Dataset/grader issue
Healthy dry run scores ↓
OUTER LOOP — Training (Finetune Scores)
Check 1: Epoch-by-epoch training scores
  Epoch N > Epoch N-1 → Learning, no overfitting ✓
  Epoch N < Epoch N-1 → Overfitting → use earlier epoch
  Epoch N ≈ Epoch 1 → No improvement → back to inner loop

Check 2: Reward hacking detection
  Training scores up but quality down?
  → Run dry run on fine-tuned model
  → Inspect high-scoring outputs manually
  → Fix grader with discriminative criteria

Check 3: Post-training dry run eval
  Fine-tuned dry run >> Base dry run → Training worked ✓
  Fine-tuned dry run ≈ Base dry run → Didn't help
  Fine-tuned dry run < Base dry run → Made it worse

Outcome:
  All good → DEPLOY ✓
  Some topics failed → Back to inner loop for those
  Overfitting → Reduce epochs or add data
  Reward hacking → Fix grader, re-train
FIVE ADJUSTABLE LEVERS
L1 Grader content — criteria, strictness, rubric (dry run scores)
L2 Record content — prompt clarity, specificity (dry run scores)
L3 Record distribution — count, balance, variety (dry run scores)
L4 Training config — epochs, LR, batch size (training scores)
L5 Topic hierarchy — split, merge, restructure (dry run scores)
