3 Preface

Progressive Chess is a chess variant in which the number of consecutive moves increases by one each turn. White starts with one move, then Black makes two consecutive moves, White responds with three, and so on.

This unique mechanic fundamentally changes the strategic landscape of chess, creating exciting tactical opportunities that don't exist in standard chess...
